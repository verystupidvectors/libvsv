# Introduction

libvsv is a fast and simple native-C replacement for
the std::vector class.

## Why prefer libvsv?

My answer is simple - C compiles faster then C++.

For years I have been constrained to the horribly
slow compile speeds of C++, and there was really no
C++ feature that I felt I needed... other then vectors.

So, this is my custom, feature-complete reimplementation for C++ dynamic arrays.

I'll never have to write another line of C++ again!

A simple example is available in the `ex/` directory.
